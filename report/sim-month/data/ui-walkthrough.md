## 环境问题（非产品 bug，但影响走查与所有真实用户）

- **E0. dev server 代理失效**：`localhost:5173` 的 vite 代理指向一个没在监听的端口（应为 `VITE_API_PROXY_TARGET` 覆盖了默认的 5108，指向未启动的 Docker API :8080），导致 UI 登录请求 502。页面把 502 显示成「登录失败，请检查邮箱和密码」——**网关错误被误报为凭证错误**，这个报错文案本身是产品问题（截图 `00-login.png`）。走查通过 Playwright route 把 `/api/**` 转发到 5108 绕过。

## 逐页观察

### 1. /dashboard（`01-dashboard.png` → `01b-dashboard-plan.png`）

- **O1. 计划卡/洞察卡出现极慢且无加载态**：首屏 3s 时只有 5 个模块卡，`今日学习计划` 和 `学习洞察` 卡要等 ~10-25s 才插入（planner 接口慢），期间无骨架屏无提示，像「今天什么计划都没有」。
- **O2. 探索期徽章与计划内容到位**：加载完成后显示「探索期·积累数据后更精准」徽章、「问路导航、日常起居 · 第 2/7 天」、造句目标 dust/not myself/cluttered，中文场景名映射正常。但徽章文案只说了「更精准」，**没有告诉用户「积累数据」具体要做什么**，引导性弱。
- **O3. 洞察卡一个月数据下形同虚设**：「近期学习状态良好，未发现明显瓶颈。」——30 天 207 条学习记录、拼写正确率仅 62% 的用户收到这句话，既没有洞察也没有行动建议。

### 2. /learn（`02-learn.png`、`02b-learn-answered.png`)

- **O4. 答错反馈信息完整**：释义、例句、下次复习间隔、阶段与掌握度都有，交互顺畅。但「难度 50」「掌握度 25%」「阶段 认识」等内部评分数值直接暴露给菜鸟，术语无解释。

### 3. /sentence（`03-sentence.png`、`03b-sentence-tab2.png`、`03c-sentence-scoring.png`、`03d-sentence-feedback.png`）

- **O5. 评分结果的第一眼冲击过于负面**：提交语法正确但未用目标词的句子 → 大字号「需重写」+ 黑体 D，语法 5/5 与总分 D 并排出现，菜鸟会困惑「我语法满分为什么是 D」。解释（问题分析「未使用目标词 dust…」）其实有，但在视口外需要滚动才发现；建议把一句话原因提到 D 旁边。
- **O6. 反馈文案泄露内部字段**：问题分析里出现「指定场景 'directions'（指路/指示）」——内部场景 key 直接外露，且 directions 被解释成「指路/指示」，和计划卡的「问路导航」口径不一致。
- 评分耗时 ~10-16s，有中间态可截（`03c`），可接受。

### 4. /reading（`04-reading.png`）

- **O7. 英文/内部字段泄露集中区**：难度筛选显示英文「All」；分区标题英文大写「ADVANCED / C2」；文章 meta 出现「Builtin · environment」「technology」等内部字段。今日推荐（来自今日计划）正常给出 3 篇 B2 文章。

### 5. /reading/:id（`05-reading-detail.png`、`05b-word-lookup.png`、`05c-word-lookup-result.png`）

- **O8. 查词弹层内容好但慢**：弹层有音标、熟悉度 50%、语境化释义和用法说明，质量高；但点词后「查词中…」持续 >2.5s 才出结果（LLM 调用），loading 只是角落小字，期间用户不确定是否点中了。

### 6. /profile（`06-profile.png`、`06c-profile-mid.png`、`06d-profile-mid2.png`、`06b-profile-bottom.png`）

- **O9. AI 评估报告陈旧且自相矛盾**：三维 Score 全是 64/64/64，报告却写「词汇能力较强（64 分）」「阅读相对薄弱（64 分）」——同分既强又弱，明显是首次测评的模板结论，一个月数据没有反映进报告；「Overall 64」「Initial」英文外露。
- **O10. 等级历史「什么都没发生」**：30 天学习后等级历史只有一条 A1→B2（原因 Initial），分数、等级无任何演进记录，与 207 条学习日志形成反差——正是 VISION 说的「分数只是外壳」目前连外壳都没动。
- 同分 64 映射出 C1（词汇）/A1（拼写）/B2（造句）/B1（阅读）四个差距巨大的 CEFR 标签，并排展示逻辑上刺眼（虽然符合"各维独立映射"设计，菜鸟会困惑）。

### 7. /review（`07-review.png`）

- **O11. 最近记录评分口径混乱**：同一列表里混用字母档（D/B/C）和英文 correct/missed，中文界面中突兀；字母档无图例，用户不知道 B 算不算好。170 待复习 vs 队列显示 1/10，两个数字的关系没有说明。

### 8. /challenge（`08-challenge.png`、`08b-challenge-bottom.png`）

- **O12. 4 次挑战记录正常**，节奏清晰可见（7/7→7/28 每周一次，最近 85 分通过）。但「造句 3」无满分参照无单位，看不懂 3 意味着什么；挑战定级 C1 对 B2 用户没有解释。

### 9. /assessment（`09-assessment.png`）

- **O13. 老用户看到「首次水平测评」**：已有 B2 等级和一个月数据的用户进入 /assessment 仍显示「首次水平测评 · 开始测评」，文案与用户状态不符；结果页无独立路由可达。

## 汇总：最需要顾言关注的 5 件事

1. 评估报告陈旧矛盾（O9）——一个月数据没进报告，违背「画像是内核」的愿景。
2. 等级/分数 30 天零变化（O10）——用户看不到成长，外壳失效。
3. 计划/洞察卡加载慢且无骨架（O1）+ 洞察无行动建议（O3）。
4. 造句评分「D+语法 5/5」的第一眼困惑（O5），原因要前置。
5. 英文与内部字段泄露（O6/O7/O9/O11）：directions、Builtin、All、correct/missed、Overall、Initial。
