# NextWord 前端功能与交互逻辑

> 文档版本：2026-06-25  
> 用途：供设计师美化 UI、优化交互时参考。基于当前前端代码实现整理。  
> 技术栈：React 19 + Vite + TypeScript + Tailwind CSS 4（无 URL 路由，页面由 `view` 状态切换）

---

## 1. 应用架构总览

### 1.1 导航模型

```
┌─────────────────────────────────────────────────────────┐
│  顶栏：Logo · 问候语 · [返回首页] · 用户头像            │
└─────────────────────────────────────────────────────────┘
                          │
          ┌───────────────┼───────────────┐
          ▼               ▼               ▼
    未登录            学习中心          我的（头像）
   LoginPage         Dashboard        ProfilePage
                          │               │
        ┌─────────────────┼───────┐       ├── 测评
        ▼         ▼       ▼       ▼       ├── 挑战
      学习      拼写    造句    阅读       └── 词库
        │                         │
        ▼                         ▼
      等级/复习/进度          文库 → 阅读器
```

| 层级 | 说明 |
|------|------|
| **无路由** | 所有页面由 `App.tsx` 的 `view` 状态切换，刷新会回到默认页 |
| **顶栏固定** | Logo、问候语、条件性「返回首页」、用户头像 |
| **二级导航** | 阅读模块内：文库 ↔ 文章阅读器 |

### 1.2 全局状态与引导

| 条件 | 行为 |
|------|------|
| 未登录 | 全屏登录页（顶栏简化版 + 登录/注册表单） |
| 已登录但未完成初测 | **强制跳转**测评页，隐藏「返回首页」 |
| 已完成初测 + 升级候选 | Dashboard 顶部显示升级候选横幅（可关闭，记忆在 localStorage） |
| 加载中 | 全屏或主区「加载中...」占位 |

**说明**：`OnboardingBanner` 组件已实现但当前未接入 App；初测引导靠自动跳转完成。

## 3. 页面功能详解

### 3.1 登录 / 注册

**入口**：未登录时全屏；已登录后在「我的」页内嵌（未登录分支）。

| 交互 | 逻辑 |
|------|------|
| Tab 切换 | 登录 ↔ 注册 |
| 注册字段 | 昵称（可选）、邮箱、密码（≥6 位） |
| 提交 | JWT 写入 localStorage，刷新后保持登录 |
| 错误 | 红色文案提示 |

---

### 3.2 学习中心（Dashboard）

**7 张功能卡片**，点击进入对应模块：

| 卡片 | 描述文案 | 目标页 |
|------|----------|--------|
| 学习 | 新词记忆，巩固词汇 | 背单词 |
| 拼写 | 听写与拼写练习 | 拼写 |
| 造句 | AI 辅助造句评分 | 造句 |
| 阅读 | 分级短文阅读 | 阅读 |
| 等级 | 查看各维度等级 | 等级 |
| 复习 | 待复习词汇队列 | 复习 |
| 进度 | 学习统计与记录 | 进度 |

**未在 Dashboard 露出**：测评、挑战、词库 → 仅在「我的」页的「更多功能」中。

---

### 3.3 学习 · 背单词

**目标**：每日新词队列（默认 8 个），SM-2 间隔重复。

**流程**：

```
加载队列 → 展示单词 → 输入中文 → 主观评分 → 查看反馈 → 下一词 → … → 完成
```

| 状态 | UI |
|------|-----|
| 加载中 | 白色卡片「正在加载今日单词...」 |
| 错误 | 红色区域 + 重试按钮 |
| 完成 | 「今日新词完成」+ 重新加载 |
| 学习中 | 左：进度条 + 单词展示 + 输入框 + 评分按钮；右：反馈区 + 目标说明 |

| 交互细节 | 说明 |
|----------|------|
| 进度 | 第 N/总数 + 百分比进度条 |
| 输入答案 | 文本框，Enter 提交（默认按「模糊」评分） |
| 主观评分 | **记住** / **模糊** / **不会** 三按钮（绿 / 琥珀 / 红） |
| 提交后 | 输入禁用；显示「上一个 / 下一个」导航 |
| 反馈侧栏 | 释义、例句、掌握度%、下次复习间隔天数；对错图标 |

---

### 3.4 拼写

**目标**：中文释义 → 英文拼写，错误位置高亮。

| 区域 | 内容 |
|------|------|
| 题干 | 中文释义 + 词性/音标 + TTS 播放按钮 |
| 输入 | 拼写输入框，提交拼写 |
| 提交前 | 「再想想」按钮（增加尝试次数） |
| 提交后 | 错误字符高亮对比；成功/失败状态卡片；例句侧栏 |
| 导航 | 提交后才显示上/下一词 |

---

### 3.5 造句

**顶部 Tab**：指定词 | 自由表达

#### A. 指定词造句

| 步骤 | 交互 |
|------|------|
| 1 | 展示目标词、CEFR 标签、场景描述段落 |
| 2 | 选择场景：**生活 / 职场 / 学术** |
| 3 | 文本框写句子（英文 placeholder） |
| 4 | 「提交评分」→ AI 评分 |
| 5 | 评分后显示「下一题」；侧栏展示反馈 |

**侧栏反馈**：

- 表达状态标签：**稳定 / 可用 / 需打磨 / 需重写**（按语法、自然度、词汇、相关性四维均分）
- 四维分数卡片
- AI 改写建议
- 错误标签 + 改进建议

队列 10 道题，可前后翻页。

#### B. 自由表达

| 交互 | 说明 |
|------|------|
| 输入 | 2–5 句英文长文本 |
| 提交 | 「获取反馈」 |
| 结果 | 综合分 /100、等级标签、AI 改写、逐句错误分析 |

---

### 3.6 阅读

#### 文库页

| 交互 | 说明 |
|------|------|
| 筛选 | 下拉：全部 / Basic / Intermediate / Advanced |
| 列表 | 按「难度 / CEFR」分组；每篇显示标题、词数、来源、话题 |
| 进入 | 点击「阅读」→ 文章阅读器 |

#### 阅读器

```
顶栏: [返回文库] ————————— [完成阅读]
正文区: 可点击单词查词 + 右侧释义浮层
底部: 重点词汇提取面板 + 段落评论
```

| 功能 | 交互逻辑 |
|------|----------|
| 点击查词 | 文中英文词可点击 → 右侧弹出释义；累计查词次数 |
| 完成阅读 | 上报阅读日志（含评论数） |
| 词汇提取 | 「提取词汇」/「重新提取」→ AI 生成表格（单词 / 文中含义 / 用法）；点击单词可查词 |
| 评论 | 手动填段落索引、段落原文、评论内容；可选「请求 AI 回复」；列表展示历史评论 + AI 回复 |

**体验缺口**：评论需手动填段落索引，点击单词未自动带入段落上下文。

---

### 3.7 首次测评

**5 步流程**，顶部时间线可点击已到达步骤回跳。

| 步骤 | 名称 | 题型 | 导航逻辑 |
|------|------|------|----------|
| 1 | 词汇识别 | 看英文选中文释义（单选标签） | 逐题「下一个」，末题「下一步」批量提交 |
| 2 | 拼写 | 看中文写英文 | 同上 |
| 3 | 造句 | 用指定词造句 | 同上 |
| 4 | 阅读 | 读短文 + 选择题 | 单题，「提交并定级」 |
| 5 | 定级 | 结果页 | 展示总体 + 四维等级 |

| 全局规则 | 说明 |
|----------|------|
| 未完成初测 | 登录后 **自动开始** |
| 阶段提交 | 必须答完本阶段全部题目才能进入下一步 |
| 未完成时 | 无法通过「返回首页」离开测评 |
| 完成后 | 自动回学习中心 |

---

### 3.8 挑战

**入口**：仅「我的」→ 挑战（Dashboard 无入口）。

**3 阶段**：词汇 → 造句 → 阅读

| 阶段 | 交互 |
|------|------|
| 词汇 | 多道选择题，逐题导航，末题进入造句 |
| 造句 | 写句子 → 「提交评分」（AI）→ 显示分数 → 「下一步」 |
| 阅读 | 读摘要 + 选择题 → 「提交挑战结果」 |
| 结果 | 成功 / 未通过 + 总分 |

---

### 3.9 等级

| 区块 | 内容 |
|------|------|
| 头部 | 总体等级；升级候选标记 |
| 四维卡片 | 词汇 / 拼写 / 造句 / 阅读 CEFR 等级 |
| 历史 | 近期等级变更记录（from → to · reason） |

只读展示，无操作按钮。

### 3.10 复习

| 区域 | 内容 |
|------|------|
| 主区 | 到期复习词；**翻转卡片式**：先显示英文，点「显示释义」揭示中文 |
| 导航 | 上/下词翻页 |
| 侧栏 | 活动统计（造句/自由表达/拼写次数、拼写正确率） |
| 侧栏 | 最近学习记录列表 |
| 刷新 | 右上角刷新按钮 |

**说明**：复习页为浏览式复习，**不写入 SM-2 评分**。

### 3.12 我的 / 个人主页

| 区块 | 功能 |
|------|------|
| 用户信息 | 昵称、邮箱、总体等级、升级候选、退出登录 |

## 5. 用户旅程（参考）

### 新用户

1. 注册 / 登录
2. 强制完成 5 步初测
3. 查看定级结果 → 进入学习中心
4. 选择模块开始日常学习

### 日常学习

1. 学习中心选模块（背单词 / 拼写 / 造句 / 阅读）
2. 完成练习，查看 AI 反馈或查词
3. 复习页浏览到期词汇
4. 进度 / 等级页查看统计

### 进阶

1. 满足条件后出现「升级候选」横幅
2. 前往等级页查看建议
3. 「我的」→ 挑战，参加综合挑战

## 6. 设计优化机会

### P0 — 信息架构

1. **入口分散**：测评 / 挑战 / 词库藏在「我的」，Dashboard 无入口；建议统一导航或底部 Tab。
2. **初测强制跳转**：新用户无法先浏览再测评；需确认是否为产品意图。
3. **无 URL 路由**：无法分享、刷新丢状态、浏览器后退无效。

### P1 — 交互体验

4. **阅读评论**：段落索引手填，体验割裂；点击段落应自动带入上下文。
5. **复习页**：只看不评，与「学习」模块 SM-2 闭环断裂。
6. **造句等级**：反馈请求中用户等级暂为固定值，可能与实际等级不符。
7. **完成态弱反馈**：背单词完成、阅读完成等缺少庆祝或引导下一步。

### P2 — 视觉一致性

8. **Design Token**：沉淀主色、状态色、圆角、间距、字号体系。
9. **加载态**：多为纯文字，可统一 Skeleton。
10. **空状态**：「暂无数据」可配图 + 行动引导。

### P3 — 后端已有、前端未接入

- 阅读辅助 Agent
- LLM 难度分级 API
- 挑战历史记录
- OnboardingBanner 引导横幅
