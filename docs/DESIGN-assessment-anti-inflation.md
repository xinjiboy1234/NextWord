# 设计方案：测评定级防伪闸——识别参考做虚高矫正（T-041）

> 状态：已定稿（2026-07-30，顾言）
> 依据：report/qa-t034/RESULT.md（菜鸟剧本定级 75→B2、词汇识别参考仅 33，产出池全 B2 习语致毕业链路结构性不可达）
> 前置：T-023 分带校准、T-027 评分挑战度、T-040 短语命中

## 1. 问题

T-023 把 64→B2 修成了 64→B1，但三轮仿真定级一路走高（64→72→75）：LLM 对「简单但正确」的产出给分慷慨，自适应升带阈值 60 又低，菜鸟被一路抬上 B2。定级虚高的代价不止是面子问题——产出池（造句目标/毕业候选）按定级带取词，B2 池词对菜鸟不可及，毕业链路（T-034）结构性不可达。

同一份测评里其实有对照信号：词汇识别参考分只有 33（≈A2）。**表达 B2 + 识别 A2，差距两档以上，说明表达分被注水**——识别题不参与定级的原则不变（I2 决策：表达力才是主定级），但它可以当「防伪闸」。

## 2. 方案（顾言拍板）：两道闸，都只挡虚高不改主口径

### 2.1 升带阈值上调

自适应分块升带阈值 60 → **70**（降带 <40 不变）。理由：T-027 后 at-band 简单正确句拿高分是设计内公平（不能罚菜鸟），但「升带」应当要求稳定的好——60 在慷慨评分下等于不设防。配合块数上限不变，弱者更早降带收敛。

### 2.2 识别防伪闸（定级后矫正，一次性）

主定级（表达力综合分 → 分带）不变，定级完成后加一道矫正：

- 计算「表达定级档」与「词汇识别参考档」的档差（A1=1…C2=6）；
- **档差 ≥2 时，定级下调 1 档**（C1 封顶规则不变，A1 为下限），评估报告与结果页明示：「表达表现 {原定级}，综合词汇掌握情况调整为 {最终定级}」——矫正理由对用户透明，不暗改；
- 识别参考样本缺失（用户全跳过识别题）时不矫正；
- 反向不处理：识别高、表达低 → 表达定级已经是低位，无需闸。

### 2.3 不做什么

- 不把识别分加权进表达力综合分（I2 的「识别仅参考」原则不变，识别只做一次性矫正信号）；
- 不动 T-023 分带表、不动 T-027 评分 prompt；
- 学习中的水平带随 Score 变化（T-022 回写）自然演化，本闸只管首测定级这一刻。

## 3. 约束

- 阈值与档差参数留常量/配置（70、2 档），后续按仿真再校准；
- 矫正留痕：Assessment 记录原定级与矫正后定级，评估报告可解释；
- 确认挑战路径不受影响（挑战通过升级走既有规则）。

## 4. 验收标准

1. 仿真菜鸟剧本重跑（表达 72-75 + 词汇识别 ≤35）：最终定级 ≤B1，结果页与报告含矫正说明；
2. 表达与识别同档的用户（档差 <2）：定级不矫正，与主口径一致；
3. 升带阈值 70：块表现 65 不再升带（原路径单测更新）、75 升带；
4. 识别样本缺失时不矫正不报错；
5. 矫正留痕可查（Assessment 记录/报告含原定级）。
