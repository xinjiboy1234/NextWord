# 设计方案：词毕业四阶段生命周期（T-014）

> 状态：已定稿（2026-07-25，顾言）
> 依据：VISION-expression-first.md §5.2（背词功能重新定位）
> 前置：SM-2（成熟）、T-006 Planner 造句目标、T-007 安全词检测（plan 目标词在自由产出的出现率——正是自发使用的检测雏形）

## 1. 定位

词的毕业标准是「**能用**」不是「认识」（VISION §5.2-2）。背词从主循环降级为输入层后，词的生命周期需要四阶段闭环；「Remembered/Forgot」自评只影响 SM-2 排程，**不再参与掌握度与 Score 计算**——掌握度只看产出端证据（§5.2-3）。

## 2. 四阶段状态机（顾言拍板）

```
认识 recognized（看词知义）→ 回忆 recalled（看义想词）→ 造句使用 prompted_use（提示下产出）→ 自发使用 spontaneous_use（毕业）
```

| 流转 | 推进条件 |
|---|---|
| 认识 → 回忆 | SM-2 调度内：看词知义自评连续正确达到 SM-2 成熟阈值（复用现有 repetitions/interval 口径，不新造指标） |
| 回忆 → 造句使用 | 回忆模式考察通过（看义能正确拼/说出词）→ 进入产出候选池 |
| 造句使用 → 待自发 | 提示造句中**正确使用**该词（造句 LLM 评分确认目标词使用正确且句子达标） |
| 待自发 → 自发使用（毕业） | **自由表达**（非指定目标词的产出任务）中自发使用一次且当次评分达标——复用 T-007 安全词检测的出现率机制做词级判定。**评分达标口径（T-044 放宽，2026-08-06 顾言裁定）**：整篇 C 及以上且词汇维 ≥3 即达标（D 档或词汇维 ≤2 仍不毕业，防烂底线不动；放宽前要求整篇 A/B，qa-t039 实测菜鸟人设 12 篇全 C/D → 判定从未执行、毕业 0）。造句确认门槛（A/B）与命中口径（T-040）不动 |

回退：产出端证据显示不会用（造句中目标词使用错误）→ 退回回忆阶段重进 SM-2 调度。**认识/回忆阶段不回退**（SM-2 自己管遗忘调度）。

## 3. 职责划分

- **SM-2**：只管前两阶段（认识/回忆）的调度——这正是它最擅长的被动词汇建设；自评（Remembered/Forgot）只改 SM-2 排程参数（interval/repetitions），**不碰掌握度、不碰 Score**；
- **规划器（Planner）**：产出候选池的词优先编入 Plan 造句目标（产出阶段任务由规划器安排，§5.2-2）；
- **掌握度**：改为阶段派生——recognized/recalled 只算「认识」，prompted_use 算「会用」，spontaneous_use 才算「毕业」；展示给用户的是阶段进度，不是百分比数字游戏。

## 4. 数据与接口

- `UserWordRelationship` 增加 `LifecycleStage`（枚举存字符串）与阶段推进时间；
- 背词接口按阶段返回考察模式（认识=看词知义，回忆=看义想词）——前端最小适配；
- 产出候选池查询接口供 Planner 消费；
- 毕业事件留痕（哪个词、在哪条 SentenceLog 中自发使用）——画像与瓶颈洞察可引用。

## 5. 验收标准（给周密）

1. 四阶段流转正确：各推进条件与回退规则有测试覆盖（含边界）；
2. 自评只影响 SM-2 排程：Remembered/Forgot 前后掌握度与 Score 不变（对比测试）；
3. 产出候选池的词被 Planner 优先编入造句目标；
4. 自由产出中自发正确使用 → 毕业留痕；指定目标词的产出不算自发（防止把造句任务当自发）；
5. 存量用户数据迁移口径明确（按现有 SM-2 状态映射初始阶段，删库重建下种子即可）；
6. `dotnet test`、`npm run build` 通过。

## 6. 非目标

- 背词 UI 大改版（最小适配：考察模式随阶段切换 + 阶段标识）;
- Score 内核维度重设计（阶段先服务掌握度与规划，Score 写入点不变）。

## 7. 顺带：T-013 僵尸任务回收（同一轮）

`BackgroundJobWorker` 只捞 Pending，API 中断后 Processing 任务永久僵尸（T-007 实测暴露）。修复：启动时/定期把超时 Processing 任务重置回 Pending（带重试上限，超限标记 Failed 留痕）。
